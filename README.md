# 🐈‍⬛ Леха: ночной дозор

Мобильная браузерная игра про чёрного кота Леху, который ночью охраняет колбасу от мышей.
Один HTML-файл, без библиотек и сборки. Играется пальцем на телефоне.

**▶ Играть:** `https://ВАШ_НИК.github.io/lekha-game/` *(после включения GitHub Pages, см. ниже)*

![Иконка](icon.png)

## Как играть

- Тапай по мышам 🐭 — Леха их ловит и говорит «Поймал!».
- Не трогай пса 🐶 — Леха скажет «Блин, не то!».
- Не трогай огурцы 🥒 — Леха их боится и кричит «Аааааа!».
- Если мышь добежала до низа, она украла колбасу, и ты теряешь жизнь. Жизней пять.
- На каждом 10-м уровне 👑 тебя ждёт босс — тапай по нему, пока не победишь.

## Особенности

- **200 уровней**, которые генерируются автоматически: сложность растёт, меняются локации (кухня, гостиная, подвал, чердак, двор, ванная, спальня, крыша).
- **Звёзды за уровень** (до 3, по числу оставшихся жизней), карта уровней со страницами.
- **Озвучка** через Web Speech API (голос системы) и звуки, синтезированные Web Audio, без аудиофайлов.
- **Сохранение прогресса** в `localStorage`.
- Красивое меню, Леха следит глазами за пальцем.
- Всё нарисовано на `<canvas>`, внешних картинок нет.

## Запуск

Откройте `index.html` в браузере. Больше ничего не нужно.

Для разработки можно запустить локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий `lekha-game` и загрузите файлы из этой папки.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту игра будет доступна по адресу `https://ВАШ_НИК.github.io/lekha-game/`.

## Настройка

Всё лежит в `index.html`:

| Что менять | Где |
|---|---|
| Сложность уровней, скорость, число мышей | функция `cfg(i)` |
| Локации и их эмодзи | массив `TH` |
| Количество уровней | константа `N` (и кратность 20 для страниц) |
| Фразы Лехи | вызовы `say('...')` |
| Звуки | объект `S` |

## Известные ограничения

- Озвучка зависит от устройства: нужна установленная русская озвучка. Во встроенных браузерах приложений она может не работать, лучше открывать в Chrome или Safari.
- На iOS звук начинается только после первого касания экрана.
